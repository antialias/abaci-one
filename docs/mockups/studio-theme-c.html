Abacus Studio — pass C proposal

One theme file, studio-owned primitives, one disclosure, one notice style. Gitea #43. Nothing here moves a control; that was A and B.

Every component below is one piece of markup styled from CSS variables. Today plugs in the literals the studio ships now. Proposed is Gitea #43 as written: the same look, made consistent — one accent, one type scale, one notice, one disclosure. Honest warning: on the assembled rails it is nearly invisible. Proposed + keeps those tokens and adds structure: section headers as ruled eyebrows so the rail scans in blocks, taller controls with one radius, notices as left-bar tints instead of outlined boxes, the nested print-service panel flattened into the rail, and a primary button that looks like the one thing to press. Flip the switch on the assembled rails at the bottom; the primitives section shows all three side by side.
